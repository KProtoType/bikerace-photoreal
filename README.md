# Bikerace — Photoreal Edition

Standalone photorealistic 3D Bikerace game hosted on GitHub Pages (100% static, zero Vercel bandwidth/credits).

## Live Game
https://kprototype.github.io/bikerace-photoreal/

## Graphics Controls
- **Weather / Time of Day (`O` key or top-right button):** Sunny, Golden Hour, Post-Rain (wet asphalt & puddles)
- **Quality (`U` key or top-right button):** Ultra (4K shadows, 4x MSAA, live water reflections), High (60 fps desktop), Balanced (mobile/lightweight)
- **Compare (`I` key or top-right button):** Flip live between Photoreal and Original look
